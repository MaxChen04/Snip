# Snip 0.1.38 beta

This beta is a self-contained **Snip Dev** build for Apple Silicon Macs running macOS 14 or later. Its app version is **0.1.38**. The download is ad-hoc signed; it is **not Apple Developer ID signed or notarized**. It is a GitHub prerelease, not a stable automatic update.

## Highlights

- App content extends behind the native macOS traffic lights, removing the opaque titlebar. Header gaps and the thin top strip provide drag areas; controls and dialogs remain interactive. Opening Snip does not force fullscreen.
- Cloud setup account questions no longer briefly show an error toast when the engine stops to request input. Genuine failures still show their error.
- Browse references on the canvas or grid, arrange boards, upload images, and keep searchable notes. Inspect desktop/mobile and available light/dark captures, sections, design tokens and motion evidence.
- Capture a landing page or crawl a site, with progress, pause/resume, retry and saved checkpoints. MCP tools and copied prompts retain the selected reference, view and capture context.
- The README keeps its demo GIFs and feature documentation while leaving release announcements and downloads in GitHub Releases.

## Install this beta

Download `Snip-Dev-0.1.38-darwin-arm64.zip` and optionally verify it with the accompanying `.sha256` file. Unzip it and use **Snip Dev.app** alongside **Snip.app**. If replacing an existing Snip Dev, quit it first. Its separate test library remains outside the app; this beta does not import the stable app's personal library.

macOS may require approval in **System Settings → Privacy & Security** for this ad-hoc signed download. Update checks and native automatic installation are disabled in this versioned beta. Future beta updates require a manual download and replacement.

## Validation and limits

Publication requires typecheck, web build, core/desktop/browser tests, native desktop smoke, and a fresh packaged capture/persistence test. The titlebar build passed maintainer manual QA; automated coverage does not independently verify every drag region.

Real hosted-library setup/upgrade, real-device passkey enrollment and Developer ID signed A→B updates retain their separate acceptance requirements. This beta does not claim those paths are proven. Sites behind login or bot challenges may capture only what the browser can access; alternate themes and live clips depend on the source page.
