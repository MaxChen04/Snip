01 / Capture

One URL in.
Everything you'd want to study, out.

Choose Static page or Crawl site. A capture agent on your machine visits every page on the same domain and records it all.

▦ Screenshots

Desktop and mobile, full page.

1440px and 390px captures of every page, with cookie banners and popups closed first.

{ } Computed styles

Only what differs from defaults.

Per-element styles, ::before and ::after, keyframes, :hover rules and CSS variables.

</> HTML snapshot

A self-contained copy that still renders.

CSS inlined, CSS-in-JS materialized, web fonts embedded, scripts stripped.

◐ Motion

Scroll and hover GIFs.

Smooth 30 fps scroll recordings per page, plus hover GIFs for elements with transitions.

◆ Design tokens

The system behind the surface.

Colors, fonts, type scale, spacing, radii, shadows and transitions, extracted automatically.

▤ Collections

An infinite, sortable gallery.

Browse by Websites, Pages or Animations. Search, sort and group references into collections.

02 / How it works

Your library in the cloud.
Your browser does the heavy lifting.

  1. A

    Queue a URL

    Hit + Add in the gallery, or ask your agent to add it over MCP.

  2. B

    Capture locally

    A Playwright agent on your Mac picks up the job, crawls and records each page.

  3. C

    Store on Cloudflare

    Files land in R2, metadata in D1. Browse from any device, signed in with GitHub.

Capture runs on your machine because free cloud browsers can't crawl a whole site. Queued references simply wait until the agent is running.

03 / MCP

Your library,
inside your agent.

04 / Self-host

Yours to run.
Free on Cloudflare.

Snip runs entirely on your own Cloudflare account and your own machine. Nothing is shared, nobody else holds your library, and the free plan covers it.

  1. 1

    Clone and install

    Node 22 and a free Cloudflare account.

  2. 2

    Create a GitHub OAuth app

    It's how you, and only you, sign in.

  3. 3

    Create D1, KV and R2, then deploy

    A few wrangler commands. The README walks through each one.

  4. 4

    Start the capture agent

    Point it at your Worker and leave it running.

Terminal

# 1. get the code
git clone https://github.com/MaxChen04/Snip.git
cd Snip && npm install

# 3. provision + deploy (from web/)
npx wrangler d1 create snip
npx wrangler kv namespace create OAUTH_KV
npx wrangler r2 bucket create snip-files
npm run db:migrate:remote && npm run deploy

# 4. capture
npx playwright install chromium
npm run capture
